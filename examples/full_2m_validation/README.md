# Measured sample-run evidence

Generated by a real local execution of this project on 4 October 2026. These are synthetic-data results, not actual bank performance. The two Parquet samples contain 100 rows each; the quality and scoring reports describe the complete two-million-customer run. Re-run the project to create full datasets and your own registry entries.

The model URI and MLflow run ID in `model_manifest.json` identify the validation server used during creation, not a service available on your computer. Your run generates its own manifest and model version. The full-volume test used a real HTTP MLflow tracking server with artifact upload and model reload. Cloud and Docker deployment were not executed.
